Install CropOtter in Claude

  1. Open the download. Open the .mcpb file with Claude Desktop.
  2. Choose a Label workspace. Pick a private folder for PDFs and converted files.
  3. Save a PDF there and ask Claude. Give it the file’s path and your preferred output name and format.

This installer is unsigned and directory review is pending. Review its source and file access before installing. Claude may show an unverified-developer warning.

Finished files are saved in your workspace. This extension is for Claude Desktop on macOS 13.5+ (Apple Silicon and Intel), not Claude web or mobile. Version 0.1.2 is 117 MB with its runtime included.

Your label stays yours.

Conversion runs on your Mac. CropOtter has no account, telemetry or remote conversion service.

Tool handlers accept files and output paths inside your selected workspace. This is an application-level boundary; the extension runs with your user’s computer permissions.

Results and files you share with Claude follow Anthropic’s data policies. Using Claude is not a promise that everything stays off Anthropic’s servers.
