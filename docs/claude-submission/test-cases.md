# Reviewer reproduction

Use only `apps/web/public/sample-label.pdf` from the public repository. It contains synthetic label data. Create a private local workspace and save that PDF as `sample-label.pdf`. During extension installation choose that workspace; substitute its actual absolute path below. Do not grant blanket tool permission or use private customer files.

| Case | Request / expected result |
| --- | --- |
| Analyze | Call `cropotter_analyze` with the workspace sample path. Expected analyzed/ready, one source page, one high-confidence embedded-image crop; no raw barcode/address text. |
| Convert | Call `cropotter_convert` with that input, a fresh child output folder, formats `pdf,png,zip`, name `Order 204`, DPI 300, acknowledgement false. Expected ready, one 288 × 432 pt PDF, 1200 × 1800 PNG, ZIP containing those two files, and manifest. Names contain the chosen base. |
| Review gate | Supply explicit selections `[{"pageIndex":0}]`, a fresh output folder, and no acknowledgement. Expected `review_required`, false acknowledgement and no final artifacts/output folder. These selections choose the full page and may add barcode warnings; do not acknowledge them automatically. |
| Outside input | Ask to analyze a PDF outside the selected workspace. Expected `OUTSIDE_WORKSPACE`, without reading that file. |
| Outside output | Ask to write to a sibling directory whose name shares the workspace prefix. Expected `OUTSIDE_WORKSPACE`, without creating output. |
| No overwrite | Repeat a successful request with the same name and output folder. Expected `OUTPUT_EXISTS`; original bytes unchanged. |
| Symlink | Use a symlink path to a source or output target. Expected `UNSAFE_PATH`; no replacement or writes through the symlink. |
| Resource scope | Read the URI returned by a successful conversion: original generated bytes. Request an arbitrary `file:` URI or another process's artifact: denied. |
| No network / no separate Node | Extract the verified `.mcpb` outside the checkout; run `npm run verify:claude-extension`. It launches both bundled architectures with network denied by macOS sandbox and PATH containing no Node/npm, then performs real conversions and resource/no-overwrite/review tests. |
| ExFAT | On an ExFAT workspace use the normal conversion request, retaining spaces in the name and a new folder. Expected complete files with verified hashes, despite unsupported hard links. |

The actual host test must use Claude Desktop's installed extension tools, not shell conversion substituted by Claude. Confirm generated files independently; a conversational success statement alone is not acceptance. Physical printer scanning, Windows and Linux desktop are outside this submission's support claims.
