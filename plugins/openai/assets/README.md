# CropOtter directory icon

`cropotter-icon.png` is a 512 × 512 PNG rendering of the project's approved, owned `apps/web/public/brand/CropOtter-CO-icon.svg`. The original warm-paper background and navy paths are preserved. It uses the repository's MIT license, not third-party branding.

Generated using the existing `@napi-rs/canvas` dependency: load the SVG, draw at 512 × 512 on a canvas and export PNG. The same square asset serves the listing and composer. Actual 48px and 128px renderings were checked on white and #212121 backgrounds; its opaque paper background preserves contrast in both themes.
